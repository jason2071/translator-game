# คู่มือ: แปลเกม Unity ด้วย XUnity

ให้ XUnity สร้าง cache อังกฤษ → แอปแปลข้อความต้นฉบับฝั่งซ้ายเป็นไทย → XUnity โหลดไทยกลับจาก cache เดิม.

คู่มือนี้รองรับ **เฉพาะ** ไฟล์นี้:

```text
BepInEx\Translation\en\Text\_AutoGeneratedTranslations.txt
```

## ต้องมี

- เกม Unity บน Windows และสิทธิ์เขียนในโฟลเดอร์เกม
- [BepInEx releases](https://github.com/BepInEx/BepInEx/releases)
- [XUnity.AutoTranslator releases](https://github.com/bbepis/XUnity.AutoTranslator/releases)
- แอปแปลเกมนี้
- ฟอนต์ TMP ที่ตรงกับเวอร์ชัน Unity หากเกมไม่มีอักษรไทย

เลือกแพ็กเกจให้ตรง runtime ก่อน:

| Runtime เกม | BepInEx | XUnity |
|---|---|---|
| Mono 64-bit | `Unity.Mono-win-x64` (BepInEx 5) | `XUnity.AutoTranslator-BepInEx-<version>.zip` |
| IL2CPP 64-bit | BepInEx 6 IL2CPP | `XUnity.AutoTranslator-BepInEx-IL2CPP-<version>.zip` |

> อย่าสลับ Mono กับ IL2CPP. ตรวจ runtime และ bitness ของเกมให้ตรงกับแพ็กเกจก่อนแตกไฟล์.

## ตั้งค่าเกม Unity ทุกเกม

ให้คำว่า **โฟลเดอร์เกม** หมายถึงโฟลเดอร์เดียวกับไฟล์ `.exe` ของเกม เช่น
`Game.exe` และ `Game_Data` อยู่ข้างกัน.

**Step 1 — ปิดเกม แล้ว backup config ก่อนแก้**

คัดลอก `BepInEx\config\AutoTranslatorConfig.ini` เป็น
`AutoTranslatorConfig.ini.before-thai` ไว้ในโฟลเดอร์เดิม.

→ ใช้ไฟล์ `.before-thai` คืนค่าได้หากตั้งค่าผิด.

**Step 2 — ติดตั้ง BepInEx และ XUnity ที่ root ของเกม**

แตกไฟล์ **ทั้งหมด** จาก `BepInEx 5 Unity.Mono-win-x64` ลงใน **โฟลเดอร์เกม** ก่อน.
จากนั้นแตกไฟล์ **ทั้งหมด** จาก `XUnity.AutoTranslator-BepInEx-<version>.zip`
ลงใน **โฟลเดอร์เกมเดียวกัน**. อย่าวาง zip ไว้เฉย ๆ และอย่าซ้อนโฟลเดอร์เพิ่ม.

สำหรับเกม IL2CPP ให้แทนสองไฟล์นี้ด้วย BepInEx 6 IL2CPP และ
`XUnity.AutoTranslator-BepInEx-IL2CPP-<version>.zip`.

หลังแตกไฟล์ โครงสร้างต้องมีดังนี้:

```text
<โฟลเดอร์เกม>\BepInEx\plugins\XUnity.AutoTranslator\
```

→ เปิดเกมหนึ่งครั้งแล้วปิด เพื่อให้ XUnity สร้าง `AutoTranslatorConfig.ini` หากยังไม่มี.

**Step 3 — วางฟอนต์ไทยไว้ข้างไฟล์ `.exe` ของเกม**

คัดลอกไฟล์ asset bundle ของฟอนต์ไทยไปยัง **โฟลเดอร์เกม** (ข้าง `.exe`), ไม่ใช่
`BepInEx\plugins` และไม่ใช่ `BepInEx\config`.

```text
arialuni_sdf_u2022
  → <โฟลเดอร์เกม>\arialuni_sdf_u2022
```

→ ชื่อที่ใส่ใน config ต้องตรงกับชื่อไฟล์ที่คัดลอกทุกตัวอักษร. เลือก bundle ให้ตรง
Unity version ของเกม เช่น `arialuni_sdf_u2022` สำหรับ Unity 2022.

**Step 4 — ตั้งค่า XUnity**

เปิดไฟล์นี้ด้วย text editor:

```text
<โฟลเดอร์เกม>\BepInEx\config\AutoTranslatorConfig.ini
```

แก้หรือเพิ่มค่าเหล่านี้ใน section เดิม:

```ini
[General]
Language=en
FromLanguage=ja

[Files]
Directory=Translation\{Lang}\Text
OutputFile=Translation\{Lang}\Text\_AutoGeneratedTranslations.txt

[TextFrameworks]
EnableTextMeshPro=True

[Behaviour]
FallbackFontTextMeshPro=arialuni_sdf_u2022
```

→ `Language=en` สำคัญ: แอปจะเห็น **เฉพาะ** cache ในโฟลเดอร์ `Translation\en\Text`.
`FromLanguage=ja` เหมาะกับเกมญี่ปุ่น; เกมจีนเปลี่ยนเป็น `zh`, เกมอังกฤษเป็น `en`.

**Step 5 — ให้ XUnity สร้างรายการข้อความ**

เปิดเกม เดินเข้าเมนู/ฉาก/บทพูดที่ต้องการให้ครบ แล้วปิดเกม. ตรวจว่าไฟล์นี้มีอยู่และมีบรรทัด `ข้อความ=คำแปล`:

```text
<โฟลเดอร์เกม>\BepInEx\Translation\en\Text\_AutoGeneratedTranslations.txt
```

→ ฝั่งซ้ายของ `=` คือข้อความต้นฉบับที่แอปจะแปล. ฝั่งขวาเป็น cache อังกฤษของ XUnity ใช้อ้างอิงได้ แต่ไม่ถือว่าแปลเสร็จ.

**Step 6 — แปลในแอป**

เปิดแอป → Open game folder → เลือก **โฟลเดอร์เกม**.

```text
<โฟลเดอร์เกม>
```

เลือกภาษาเป้าหมาย Thai → กด **Run** → ตรวจคำแปล → กด **Export → game**.

→ แอปเขียนไทยกลับไปที่ฝั่งขวาของ `=` ใน `_AutoGeneratedTranslations.txt` โดยไม่แก้ข้อความต้นฉบับฝั่งซ้าย.

**Step 7 — โหลดไทยในเกม**

เปิดเกมใหม่ หรือกด `Alt` + `R` ในเกมเพื่อให้ XUnity reload ไฟล์คำแปล.

→ ข้อความที่แปลแล้วควรเป็นไทย. เข้าเกมเพิ่มเพื่อเก็บข้อความที่ยังไม่เคยเห็น แล้วกลับไปกด rescan ในแอปและแปลซ้ำได้.

## ย้อนกลับแบบทำมือ

⚠️ ปิดเกมก่อน. เปลี่ยนชื่อ `AutoTranslatorConfig.ini.before-thai` กลับเป็น
`AutoTranslatorConfig.ini` แล้วลบเฉพาะไฟล์ bundle ที่คุณคัดลอกไว้ในโฟลเดอร์เกม.

หากต้องการคืนข้อความอังกฤษที่ XUnity สร้างไว้ ให้ใช้ backup ของ
`_AutoGeneratedTranslations.txt` ที่คุณเก็บก่อน Export; การลบไฟล์นี้ทำให้ XUnity สร้าง cache ใหม่เมื่อเปิดเกม.

## จุดที่มักพลาด

- **แอปไม่พบเกมแบบ XUnity** — ต้องเปิดเกมก่อนจนมีไฟล์
  `BepInEx\Translation\en\Text\_AutoGeneratedTranslations.txt` และในไฟล์ต้องมีอย่างน้อยหนึ่งบรรทัด `ซ้าย=ขวา`.
- **cache ไปอยู่ `Translation\ja` หรือ `Translation\th`** — เปลี่ยน `[General] Language=en`, เปิดเกมอีกครั้ง. แอปรองรับ path `en` เท่านั้น.
- **ตัวไทยเป็น □□□** — ชื่อไฟล์ใน `FallbackFontTextMeshPro` ต้องตรงกับ bundle ที่วางไว้ที่ root ของเกม. สำหรับเกมตัวอย่าง Unity 2022 ใช้ `arialuni_sdf_u2022`; bundle คนละเวอร์ชัน Unity อาจไม่โหลด.
- **ข้อความไม่ถูกจับ** — ลองกด `Alt` + `U` ในเกม แล้วเปิดฉากนั้นใหม่. XUnity ระบุว่าบาง text framework ไม่เปิดโดยค่าเริ่มต้น; ตรวจ `BepInEx\LogOutput.log` หากยังไม่พบข้อความ.
- **แก้ไฟล์แล้วเกมยังเป็นภาษาเดิม** — กด `Alt` + `R` หรือปิดแล้วเปิดเกมใหม่.
